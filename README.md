# World Clock App

A simple, beautiful world clock showing time in multiple time zones.

## Features

- Real-time clock updates
- Multiple time zones (New York, London, Tokyo, Sydney)
- Clean, modern design
- Mobile responsive

## Quick Deploy to Vercel

```bash
npx vercel deploy --prod
```

## Setup with GitHub

```bash
git init
git add .
git commit -m "Initial commit"
gh repo create world-clock --public --source=. --push
```

Then import to Vercel from your GitHub repository.

## Local Testing

Simply open `index.html` in your browser or use:

```bash
python3 -m http.server 8000
```

Then visit: `http://localhost:8000`
